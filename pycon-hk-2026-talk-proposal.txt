Title
From Voice Agent to Dating Sim: Building a Real-Time Multi-Agent Game with Amazon Nova and AgentCore

Abstract
What happens when you turn language learning into a real-time anime-style dating sim? In this talk, I’ll share how I built an interactive voice experience powered by Amazon Nova, Strands Agents, and Bedrock AgentCore — where players speak naturally with AI characters, receive live responses, and progress through multi-agent scene logic in real time.

The project started as a conversational voice app and evolved into a split-runtime multi-agent architecture: one runtime handles low-latency voice interaction, while another handles hidden orchestration, scoring, and scene progression. Along the way, I’ll show how design choices in prompt engineering, agent coordination, UX, and infrastructure changed the experience from a simple speaking practice tool into a playful, production-style AI application.

This session is for developers who want to go beyond chatbots and build real-time, character-driven, multimodal AI experiences on AWS.

Description
In this talk, I’ll walk through the architecture and product journey behind an experimental real-time AI dating-sim game built with Amazon Nova and Bedrock AgentCore.

The app combines:
- Amazon Nova 2 Sonic for low-latency voice conversation
- Strands Agents for character and hidden-agent orchestration
- Bedrock AgentCore Runtime for secure deployment and split-runtime design
- a frontend with Live2D-style character interaction and scene-based game flow

Rather than treating AI as a single chatbot, this project uses a multi-agent pattern:
- a visible voice agent talks to the player in real time
- hidden agents coordinate scene flow, guidance, and progression
- a separate analysis runtime handles slower orchestration work without blocking the live conversation

I’ll cover:
- how to design real-time multimodal AI systems that still feel responsive
- why I split the voice runtime and analysis runtime
- how hidden agents can shape UX without exposing complexity to the user
- what changed when the app shifted from “speaking practice tool” to “dating-sim-style experience”
- lessons learned about prompts, product feel, architecture trade-offs, and developer workflow on AWS

As an AWS AI Hero representing the AWS AI User Group Hong Kong, I’ll share both the technical implementation and the community perspective on building playful but serious AI demos that help people understand what modern agent systems can actually do.

This session is aimed at developers, builders, and AI enthusiasts who want practical ideas for creating richer AI-native applications — not just assistants, but experiences.
